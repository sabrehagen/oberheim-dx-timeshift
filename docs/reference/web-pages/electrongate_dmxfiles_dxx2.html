DXX2 EPROM Switcher

The Electrongate DXX2 is a small circuit board that allows replacing a 2764 EPROM in the Oberheim DX with a 27128 or 27256 EPROM, and allows switching between two or four separate full length samples (or pairs of samples, for the Percussion channel) using toggle switches.
Up to five DXX2 modules can be used in the DX. The DX cymbal voice uses a different EPROM configuration, so is not compatible with the DXX2.
